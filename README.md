## نصب ویندوز
فایل setup را اجرا کنید؛ برنامه در `AppData\Local\MedVisit\<نقش>` نصب می‌شود (بدون نیاز به دسترسی Administrator). اگر Windows SmartScreen هشدار داد، روی **More info → Run anyway** بزنید.

## نصب اندروید
فایل APK را باز کنید؛ اگر پیام «منبع ناشناس» آمد، اجازه نصب را به مرورگر/فایل‌منیجر بدهید.
